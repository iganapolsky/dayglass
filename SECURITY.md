# Security

Dayglass stores OCR of your screen in `~/.dayglass/` on this Mac. That text can include work content.

- Ask and recap may call only `http://127.0.0.1`. Any other base URL is refused.
- Do not commit `~/.dayglass/`, screenshots, or the sqlite database.
- Report a vulnerability by opening a private security advisory on this repo. Do not file a public issue with screen text or tokens in it.
